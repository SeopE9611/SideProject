# 샬롬의 집 공식 홈페이지

## 기술 구성

- Next.js
- React
- TypeScript
- Tailwind CSS
- pnpm

## 실행 명령

```bash
pnpm dev
pnpm typecheck
pnpm lint
pnpm build
```

## 현재 주요 공개 경로

- `/`
- `/about`
- `/life`
- `/news`
- `/support`
- `/transparency`

홈 페이지 파일은 `src/app/(public)/page.tsx`입니다.

현재 단계에는 DB, 로그인, CMS, 배포 연결이 없습니다.
