# 샬롬의 집 공식 홈페이지

샬롬의 집 홈페이지는 시설 정보, 생활 기록, 소식, 참여 절차, 공개 자료, 연락과 방문 안내를 제공하는 공식 기관 홈페이지다.

## 실행 방법

```bash
pnpm install
pnpm dev
```

프로젝트의 기준 문서와 작업별 필독 문서는 [`docs/README.md`](./docs/README.md)에서 확인한다. fixture와 placeholder는 개발 및 Preview 검증용이며 공식 콘텐츠가 아니다. 실제 콘텐츠를 공개하기 전에는 사실관계, 개인정보, 공개 권한을 운영자가 검토하고 승인해야 한다.
