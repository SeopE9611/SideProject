# 샬롬의 집 홈페이지 콘텐츠 운영 및 공개 원칙

## 1. 문서 목적

이 문서는 샬롬의 집 공식 홈페이지 콘텐츠의 작성, 검수, 승인, 공개, 수정 원칙을 정의한다. 거주인의 존엄성과 개인정보를 보호하면서 정확한 공공 정보를 제공하기 위한 장기 운영 기준이며 법률 자문을 대신하지 않는다.

## 2. 기본 원칙

- 거주인의 존엄성과 사생활 보호를 홍보보다 우선한다.
- 공개 필요성이 명확한 최소한의 정보만 게시한다.
- 정확성이 확인되지 않은 정보는 게시하지 않는다.
- 내부용 문서를 홈페이지 공개자료로 그대로 사용하지 않는다.
- 게시 전에 개인정보와 민감정보 포함 여부를 검수한다.
- 오래된 정보는 정기적으로 검토한다.
- 외부 제보나 요청만으로 개인정보를 공개하지 않는다.
- 후원·연락·시설 정보는 공식 담당자의 확인 후 게시한다.

## 3. 콘텐츠 공개 등급

### 공개 가능

다음은 운영자 승인 후 공개할 수 있다.

- 공식 시설 소개
- 공개가 승인된 주소와 연락처
- 공개 프로그램 안내
- 개인정보가 제거된 활동 소식
- 공식 후원 안내
- 공식 자원봉사 안내
- 공개 승인된 운영 보고자료
- 개인정보가 제거된 이미지와 첨부파일

### 조건부 공개

다음은 별도 동의와 검수가 필요하다.

- 사람의 얼굴이 식별되는 사진과 영상
- 거주인의 이름 또는 별칭
- 직원의 실명과 직책
- 후원자 이름과 후원 내용
- 자원봉사자 이름과 활동 사진
- 인터뷰와 사례 이야기
- 행사 참여자의 음성
- 위치와 일정이 결합돼 개인을 추정할 수 있는 정보

### 공개 금지

다음은 홈페이지에 공개하지 않는다.

- 주민등록번호
- 상세 장애 정보와 진단명
- 의료기록과 복약 정보
- 상담 기록과 개별 서비스 지원계획
- 보호자 개인정보와 가족관계 정보
- 거주인의 개인 연락처와 직원의 개인 연락처
- 계정 비밀번호와 인증정보
- 비공개 후원자 정보
- 내부 인사자료
- 내부 사건·사고 기록과 내부 회의록
- 미승인 예산·결산 자료
- 개인정보가 포함된 원본 신청서
- 접근 제한이 필요한 내부 행정문서

## 4. 거주인 관련 정보

- 거주인은 홈페이지 콘텐츠의 홍보 수단이 아니라 권리와 존엄성을 가진 당사자다.
- 실명 공개를 기본값으로 사용하지 않는다.
- 장애 특성, 건강 상태, 가족관계, 생활기록을 활동 소개에 포함하지 않는다.
- 사례 소개는 개인을 알아볼 수 없도록 최소화한다.
- 여러 정보의 조합으로 개인을 추정할 수 있는지도 검토한다.
- 동의가 있더라도 공개 범위와 게시 기간을 별도로 검토한다.
- 동의 절차의 구체적인 법적 양식은 운영자와 전문가 확인 후 확정한다.

## 5. 사진·영상·음성

- 게시 전에 촬영 및 공개 동의를 확인한다.
- 동의 대상과 공개 채널을 확인한다.
- 배경에 문서, 이름표, 주소, 차량번호 등 개인정보가 노출되는지 확인한다.
- 원본 파일과 공개용 파일의 관리 방안은 추후 확정한다.
- 동의 철회 또는 비공개 요청을 처리할 절차를 마련해야 한다.
- 대체 텍스트는 외모나 장애를 불필요하게 묘사하지 않고 콘텐츠의 목적을 전달한다.
- 파일 메타데이터 제거 정책은 업로드 기능 구현 시 검토한다.
- 얼굴 자동 모자이크 등의 기능은 구현 여부가 미정이며 확정된 기능으로 간주하지 않는다.

## 6. 직원 및 관계자 정보

- 공식적으로 공개가 승인된 이름·직책·업무용 연락처만 게시한다.
- 개인 휴대전화와 개인 이메일은 공개하지 않는다.
- 퇴사 또는 보직 변경 시 공개 정보를 신속하게 수정한다.
- 조직도와 직원 공개 범위는 운영자 협의 후 확정한다.
- 개발자의 가족관계 또는 개인적 인연은 홈페이지 콘텐츠에 포함하지 않는다.

## 7. 후원 관련 정보

- 계좌번호, 예금주, 후원 방법은 공식 담당자의 확인 전 게시하지 않는다.
- 후원자 이름과 금액은 공개 동의 없이 게시하지 않는다.
- 후원금 사용보고 자료는 공개 승인된 최종본만 사용한다.
- 개인정보가 포함된 입금내역 원본을 게시하지 않는다.
- 온라인 결제 도입 여부는 현재 미정이다.
- 후원 관련 법적 문구와 세액공제 안내는 운영자 또는 전문가 검토 후 확정한다.

## 8. 자원봉사 관련 정보

- 신청 과정에서 필요한 정보는 최소화한다.
- 신청서와 연락처를 공개 게시물에 노출하지 않는다.
- 자원봉사자 사진과 후기 역시 별도 공개 동의를 확인한다.
- 미성년자 관련 내용은 별도 보호 기준을 검토한다.
- 자원봉사 신청 방식은 아직 확정하지 않았다.

## 9. 투명성 자료와 첨부파일

- 공개가 승인된 최종 문서만 게시한다.
- 개인정보와 내부 정보가 제거됐는지 확인한다.
- 문서 제목, 기준 기간, 게시일, 수정일을 명확히 표시한다.
- 스캔 이미지보다 접근 가능한 텍스트 또는 읽을 수 있는 PDF를 우선 검토한다.
- 파일의 내용을 이해할 수 있는 파일명을 사용한다.
- 오래되거나 잘못된 자료는 수정 이력을 남기고 교체한다.
- 공식 공개 의무와 보유기간은 운영자 또는 전문가 확인 후 확정한다.
- 법령명이나 공개 주기를 임의로 단정하지 않는다.

## 10. 게시물 작성 및 검수 절차

다음은 CMS나 승인 기능이 구현된 현재 절차가 아니라 향후 목표 절차다.

```text
작성
→ 개인정보·민감정보 확인
→ 사실관계와 공개 권한 확인
→ 접근성 확인
→ 승인
→ 공개
→ 정기 검토
→ 수정·비공개·삭제
```

역할은 `작성자`, `검수자`, `승인자`, `관리자`처럼 일반적인 이름으로 구분한다. 구체적인 담당자와 역할 분담은 운영자 협의가 필요하다.

## 11. 수정·비공개·삭제 원칙

- 잘못된 정보는 발견 즉시 검토한다.
- 개인정보 노출 가능성이 있으면 우선 비공개한 뒤 확인한다.
- 동의 철회 요청을 처리할 절차를 마련한다.
- 게시물 수정일 표시를 검토한다.
- 삭제와 비공개의 차이를 운영 정책에서 정의한다.
- 감사 기록과 복구 정책은 관리자 기능 설계 시 확정한다.
- 검색엔진에 이미 노출된 정보의 삭제 대응 절차도 향후 운영 문서에서 검토한다.

## 12. 콘텐츠 접근성

- 제목 구조를 순서대로 사용한다.
- 링크 문구만 읽어도 목적을 알 수 있게 작성한다.
- 이미지만으로 정보를 전달하지 않는다.
- 표에는 제목과 헤더를 사용한다.
- 영상에는 자막 또는 대체 수단을 검토한다.
- PDF만 제공하지 않고 핵심 내용을 웹페이지에도 제공하는 방안을 검토한다.
- 전문용어와 행정용어를 가능한 쉬운 한국어로 설명한다.
- 장문의 콘텐츠는 문단과 소제목으로 구분한다.

## 13. 보안 및 파일 관리

- 홈페이지 DB와 파일 저장소에는 공개 홈페이지 운영에 필요한 자료만 저장한다.
- 공개 금지 정보가 포함된 원본 문서나 내부 행정문서를 업로드하지 않는다.
- 업로드 기능을 구현할 때 파일 형식, 용량, 악성 파일 검사, 접근 권한, 저장 위치를 검토한다.
- 공개용 첨부파일은 다운로드 전후에도 개인정보가 드러나지 않는지 확인한다.
- 관리자 계정, 비밀번호, 인증정보를 콘텐츠나 첨부파일에 기록하지 않는다.
- 백업, 보관, 삭제, 복구, 활동 기록 정책은 관리자 기능과 저장소 설계 단계에서 결정한다.

## 14. 미확정 운영 정책

다음 항목은 모두 **확인 필요** 상태다.

- 콘텐츠 최종 승인자
- 사진·영상 동의서 양식
- 동의 보관 방식과 기간
- 공개 게시물 검수 주기
- 게시물 보존·삭제 기간
- 첨부파일 허용 형식과 최대 용량
- 관리자 역할과 권한
- 수정 이력과 감사 기록
- 개인정보 침해 신고 접수 경로
- 긴급 비공개 처리 담당자
- 후원정보 검증 담당자
- 투명성 자료 게시 주기
- 검색엔진 삭제 대응 절차

운영 책임과 실제 절차는 운영자 협의가 필요하다. 개인정보, 동의, 공개 의무 등 전문 판단이 필요한 부분은 관련 전문가 확인 후 확정한다.
