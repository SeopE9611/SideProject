# 정보구조

## 주요 방문자 과업

- 샬롬의 집이 어떤 시설인지 확인한다.
- 위치, 연락처와 방문 전 필요한 사항을 확인한다.
- 최근 공지와 활동을 확인한다.
- 자원봉사와 후원 참여 방법을 확인한다.
- 운영 및 후원 공개자료를 확인한다.

## 목표 상위 메뉴

상단 메뉴는 `시설소개`, `생활이야기`, `소식·자료`, `함께하기` 순서로 제공한다.
`자료공개`는 `소식·자료`의 하위 메뉴로 제공하되 기존 `/transparency` route를
유지한다. 구현되지 않은 미래 route는 메뉴에 노출하지 않는다.

```text
/
├─ /about
│  └─ /about/directions
├─ /life
├─ /news
│  └─ /news/[slug]
├─ /transparency
└─ /support
```

### 향후 검토 경로

인사말·연혁, 생활 세부, 후원·자원봉사 하위 페이지는 공식 콘텐츠 확보 후
구현 여부와 경로를 결정한다. `/about/greeting`, `/about/history`,
`/life/activities`, `/life/spaces`, `/support/volunteer`, `/support/donation`은
현재 공개 route나 메뉴로 표현하지 않는다.

## 메인 페이지 필수 모듈

1. 공식 기관 소개
2. 자주 찾는 업무
3. 공지사항
4. 최근 활동소식
5. 주요 생활·지원 영역
6. 생활 이야기
7. 자료공개
8. 위치와 연락

공식 콘텐츠가 없는 모듈은 명확히 구분된 fixture로 레이아웃을 검증할 수 있다.

## 반복 정보

주소와 대표번호를 정확히 두 곳에만 표시한다는 제한은 사용하지 않는다. 상단 유틸리티 영역, 푸터, 찾아오시는 길, 메인 하단 연락·방문 모듈, 문의가 필요한 참여 페이지에는 과업상 필요한 범위에서 반복할 수 있다. 중복 최소화보다 정확성, 최신성, 과업 수행 가능성을 우선한다.

## 페이지 유형

| 페이지 | 레이아웃 유형 |
| --- | --- |
| 홈 | 기관 포털형 |
| 시설소개 | 기관 개요형 |
| 생활이야기 | 사진·기록형 |
| 소식 | 검색·분류·목록형 |
| 함께하기 | 절차 안내형 |
| 자료공개 | 문서 라이브러리형 |
| 찾아오시는 길 | 지도·방문 정보형 |

같은 히어로와 같은 레이아웃을 모든 페이지에 적용하지 않는다. 각 유형의 구체적인 구조는 `page-patterns.md`가 소유한다.
