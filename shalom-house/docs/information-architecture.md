# 정보구조

## 주요 방문자 과업

- 샬롬의 집이 어떤 시설인지 확인한다.
- 위치, 연락처와 방문 전 필요한 사항을 확인한다.
- 최근 공지와 활동을 확인한다.
- 자원봉사와 후원 참여 방법을 확인한다.
- 운영 및 후원 공개자료를 확인한다.

## 목표 상위 메뉴

상단 메뉴는 `시설소개`, `생활·프로그램`, `소식`, `함께하기` 순서로 제공한다.
`자료공개`는 `소식`의 하위 메뉴로 제공하되 기존 `/transparency` route를
유지한다. 구현되지 않은 미래 route는 메뉴에 노출하지 않는다.

```text
/
├─ /about
│  ├─ /about/greeting
│  ├─ /about/people
│  ├─ /about/spaces
│  └─ /about/directions
├─ /life
│  ├─ /life/programs
│  └─ /life/gallery
├─ /news
│  ├─ /news/notices
│  ├─ /news/activities
│  ├─ /news/[slug]
│  └─ /transparency
└─ /support
   ├─ /support/donation
   ├─ /support/volunteer
   └─ /support/contact
```

`/transparency`는 URL상 `/news` 하위가 아니지만 메뉴와 탐색 구조에서는 `소식`의 하위인 `자료공개`로 제공한다.

## 메인 페이지 필수 정보와 접근 경로

1. 공식 기관 소개
2. 자주 찾는 업무
3. 공지사항
4. 최근 활동소식
5. 주요 생활·지원 영역
6. 생활 이야기
7. 자료공개
8. 위치와 연락

위 목록은 독립된 대형 섹션 8개를 요구하지 않는다. 공지와 활동소식은 최근 소식으로, 주요 생활·지원 영역과 생활 이야기는 생활·프로그램 탐색으로, 자료공개와 참여 안내는 보조 영역으로 묶을 수 있다. 기관 소개와 방문·연락은 하나의 입구 영역으로 구성할 수 있다.

데이터가 적으면 항목 수에 맞게 높이를 줄이고, 사진이 없으면 사진 영역을 생략한다. 필수 경로는 메뉴·본문 링크로 유지한다. 콘텐츠 양별 구성은 `page-patterns.md`, 테스트 데이터의 공개 범위는 `content-governance.md`를 따른다.

## 반복 정보

주소와 대표번호를 정확히 두 곳에만 표시한다는 제한은 사용하지 않는다. 상단 유틸리티 영역, 푸터, 찾아오시는 길, 메인 하단 연락·방문 모듈, 문의가 필요한 참여 페이지에는 과업상 필요한 범위에서 반복할 수 있다. 중복 최소화보다 정확성, 최신성, 과업 수행 가능성을 우선한다.

## 페이지 유형

| 페이지        | 레이아웃 유형     |
| ------------- | ----------------- |
| 홈            | 기관 포털형       |
| 시설소개      | 기관 개요형       |
| 생활이야기    | 사진·기록형       |
| 소식          | 검색·분류·목록형  |
| 함께하기      | 절차 안내형       |
| 자료공개      | 문서 라이브러리형 |
| 찾아오시는 길 | 지도·방문 정보형  |

같은 히어로와 같은 레이아웃을 모든 페이지에 적용하지 않는다. 각 유형의 구체적인 구조는 `page-patterns.md`가 소유한다.
