# 샬롬의 집 메인 페이지 운영 계획

## 1. 목적

메인 페이지는 감성 홍보용 랜딩 페이지가 아니라 시설의 정체성, 생활, 최근 소식, 참여와 공개 정보를 연결하는 공식 홈페이지의 입구다.

## 2. 현재 구조

1. 정적 히어로
2. 자주 찾는 안내
3. 일상의 세 장면
4. 최근 소식 또는 공식 채널 빈 상태
5. 함께하기와 정보공개
6. 공통 푸터

## 3. 정적 히어로

- 시설 유형과 핵심 설명을 첫 화면에서 바로 확인할 수 있어야 한다.
- 시설소개와 생활이야기를 첫 행동으로 제공한다.
- 오른쪽 영역은 생활·활동·공개 기준을 설명 목록으로 제공한다.
- 실제 운영 콘텐츠가 없는 상태에서 캐러셀을 사용하지 않는다.
- 자동 재생, 페이지 점, 이전·다음 버튼을 추가하지 않는다.

## 4. 자주 찾는 안내

- 시설 안내, 생활 이야기, 함께하기, 정보공개 네 경로만 제공한다.
- 동일 크기의 둥근 카드 대신 경계로 구분한 탐색 목록을 사용한다.
- 각 항목은 이동 결과를 한 문장으로 설명한다.

## 5. 일상의 세 장면

- 식탁, 외부 활동, 생활 공간의 세 주제를 편집형 목록으로 제공한다.
- 승인 사진이 없을 때 색면이나 아이콘으로 사진 영역을 대체하지 않는다.
- 실제 사진이 승인되면 각 주제의 내용과 직접 연결되는 사진만 추가한다.

## 6. 최근 소식

- 공개된 실제 게시물만 최대 3개 표시한다.
- 개발용 예시 게시물은 메인에서 제외한다.
- 제목, 분류, 게시일, 요약을 표시한다.
- 게시물이 없으면 첫 소식을 준비 중이라는 상태와 공식 인스타그램 경로를 제공한다.

## 7. 함께하기와 정보공개

- 참여 안내와 공개 자료를 같은 감성 메시지로 섞지 않는다.
- 후원·자원봉사 절차와 운영 자료라는 서로 다른 이동 결과를 분명히 표시한다.
- 죄책감, 불쌍함, 긴급성을 이용하는 문구를 사용하지 않는다.

## 8. 사진 도입 조건

사진을 연결하기 전에 다음을 확인한다.

- 촬영과 홈페이지 공개 동의
- 얼굴, 이름, 일정, 위치, 건강·장애 정보의 조합으로 개인을 식별할 수 있는지
- 원본 파일의 사용 권한과 출처
- 사진의 실제 촬영 시점과 설명
- 대체 텍스트

승인 조건을 충족하지 못하면 현재 텍스트 기반 레이아웃을 유지한다.

## 9. 완료 기준

- 첫 화면에서 시설 유형과 사이트 목적을 이해할 수 있다.
- 핵심 공개 경로를 두 번 이내의 이동으로 찾을 수 있다.
- 파스텔 타일, 장식 숫자, 사진 대체 그래픽이 없다.
- 모바일 320px에서 가로 스크롤이 없다.
- 키보드만으로 모든 링크와 메뉴를 사용할 수 있다.
- 동작 감소 환경에서 정보 손실이 없다.
- 실제 콘텐츠가 없을 때 가짜 내용으로 화면을 채우지 않는다.
