# 샬롬의 집 메인 랜딩 개편 기준

## 1. 목적

이 문서는 샬롬의 집 공개 사이트의 화면 규격, 상위 메뉴, 메인 랜딩 구성과 작업 순서를 정하는 현재 실행 기준이다. 사이트의 핵심은 기부 결제 전환이 아니라 장애인거주시설의 공동체 일상, 신뢰할 수 있는 정보, 지역사회 참여를 누구나 쉽게 이해하도록 안내하는 데 있다.

## 2. 한 문장 방향

**30년 넘게 함께 살아온 집의 일상을 존중하는 태도로 보여 주고, 소개·생활·소식·참여·운영 정보를 명확하게 연결하는 랜딩 페이지**

거주인을 도움이나 감동의 대상으로만 표현하지 않는다. 시설보다 사람과 일상을 먼저 말하되, 확인되지 않은 개인 정보·사진·운영 정보를 만들지 않는다.

## 3. 레퍼런스 적용 원칙

| 레퍼런스 | 참고할 점 | 샬롬의 집 적용 |
| --- | --- | --- |
| [사랑의열매](https://www.chest.or.kr/) | 참여, 문의, 투명성 정보의 분명한 분리 | `함께하기`와 `운영 공개`의 책임을 구분한다. 즉시 기부 입력 UI는 사용하지 않는다. |
| [푸르메재단](https://purme.org/) | 사업, 소식, 참여 경로의 구분 | 일상·활동과 후원·봉사를 섞지 않고 독립 흐름으로 안내한다. |
| [L'Arche International](https://www.larche.org/) | 장애인과 비장애인이 함께하는 공동체 관점 | 시설 홍보보다 함께 사는 관계와 일상을 첫 화면의 중심으로 둔다. |
| [Camphill Village Trust](https://www.camphillvillagetrust.org.uk/) | 생활, 활동, 이야기, 참여가 이어지는 랜딩 흐름 | `정체성 → 생활 → 소식 → 함께하기` 순서로 메인을 구성한다. |

색상, 로고, 문구, 사진, 코드와 화면 구성을 복제하지 않는다. 구조적 장점만 샬롬의 집의 규모와 목적에 맞게 다시 설계한다.

## 4. 화면 규격

| 항목 | 모바일 | 넓은 화면 | 코드 기준 |
| --- | ---: | ---: | --- |
| 사이트 최대 폭 | 화면 폭 | 1,280px | `max-w-site` |
| 읽기 본문 최대 폭 | 화면 폭 | 736px | `max-w-content` |
| 페이지 좌우 여백 | 20px | 48px | `px-page`, `px-page-wide` |
| 섹션 상하 여백 | 80px | 112px | `py-section`, `py-section-wide` |
| 히어로 제목 | 42px | 72px | `text-hero`, `text-hero-lg` |
| 일반 페이지 큰 제목 | 40px | 56px | `text-display`, `text-display-lg` |
| 본문 | 17px / 1.75 | 동일 | `text-body` |
| 최소 조작 영역 | 44px | 44px 이상 | `min-h-11`, `min-w-11` |

긴 본문은 사이트 최대 폭까지 늘리지 않고 읽기 폭을 제한한다. 카드 수를 채우기 위해 정보를 반복하지 않으며 구분선, 여백, 배경 변화로 콘텐츠 우선순위를 표현한다.

## 5. 상위 메뉴

| 순서 | 메뉴명 | 경로 | 책임 |
| ---: | --- | --- | --- |
| 1 | 샬롬 소개 | `/about` | 시설 소개와 기본 정보 |
| 2 | 생활과 활동 | `/life` | 함께 만드는 일상과 활동 |
| 3 | 소식과 이야기 | `/news` | 공지사항과 활동 이야기 |
| 4 | 함께하기 | `/support` | 후원과 자원봉사 문의 |
| 5 | 운영 공개 | `/transparency` | 운영 및 후원 관련 공개 자료 |

홈은 텍스트 브랜드와 로고가 담당하므로 별도 메뉴로 중복하지 않는다. 현재 각 메뉴 아래 독립 라우트가 하나뿐이므로 드롭다운을 만들지 않는다. 모바일 메뉴에서는 이름만으로 부족한 맥락을 보완하도록 한 줄 설명을 함께 제공한다.

## 6. 메인 랜딩 구성

1. 히어로 슬라이더: 30년의 보금자리, 생활과 활동, 지역사회 연결의 세 메시지
2. 정체성: 시설보다 먼저 함께 사는 집이라는 관점과 확인된 기본 정보
3. 활동 사례: 평일 점심 식사 도움, 나들이 지원, 공간복지 드림하우스
4. 최근 소식: 공개 승인된 실제 게시물 최대 3개, 없으면 정직한 빈 상태
5. 함께하기와 운영 공개: 참여 행동과 신뢰 정보를 서로 다른 영역으로 연결
6. 위치와 대표 전화: 푸터 직전 짧은 직접 안내

승인된 사진이 없는 현재 단계에서는 실제 거주인처럼 보이는 합성 인물 사진을 사용하지 않는다. 집과 창문을 연상시키는 추상 그래픽으로 구조를 완성하고, 추후 승인 사진을 받아도 정보 구조는 유지한 채 시각 요소만 교체한다.

## 7. 슬라이더 접근성 규칙

- 자동으로 움직이는 영역은 메인 히어로 한 곳만 둔다.
- 첫 렌더링 후 8초 간격으로 전환하며 이전, 다음, 특정 슬라이드 이동과 정지·재생 버튼을 제공한다.
- 포인터가 올라가거나 키보드 포커스가 내부에 있으면 자동 전환을 잠시 멈춘다.
- `prefers-reduced-motion: reduce`에서는 자동 재생을 시작하지 않는다.
- 자동 전환은 스크린리더 라이브 영역으로 반복 공지하지 않고, 사용자가 직접 조작한 변경만 알린다.
- 슬라이드가 바뀌어도 핵심 정보와 다음 경로는 키보드로 접근할 수 있어야 한다.
- 두 번째 자동 슬라이더, 자동 재생 영상·음성, 패럴랙스는 추가하지 않는다.

## 8. 구현 순서

```text
화면 규격·의미 토큰 확정
→ 상위 메뉴와 공통 헤더·푸터 개편
→ 메인 랜딩과 히어로 슬라이더 구현
→ 모바일·키보드·reduced motion·확대 검증
→ lint·typecheck·build CI 추가
→ 샬롬 소개
→ 생활과 활동
→ 소식과 이야기
→ 함께하기
→ 운영 공개
```

서브페이지는 한 번에 모두 바꾸지 않는다. 메인에서 검증한 공통 규격과 상호작용을 재사용하되, 각 페이지의 사용자 과업에 맞는 편집형·목록형·문서형 구조를 선택한다.

## 9. 완료 판단

- 320px에서 가로 스크롤이나 잘린 조작 요소가 없다.
- 키보드만으로 메뉴와 슬라이더, 모든 링크를 사용할 수 있다.
- 포커스가 sticky 헤더에 가려지지 않는다.
- 200%·400% 확대와 reduced motion에서 정보와 기능이 유지된다.
- 공개 승인되지 않은 실제 거주인 사진과 개인정보를 사용하지 않는다.
- 데모 뉴스와 가짜 통계, 작동하지 않는 입력 폼을 메인에 노출하지 않는다.
- 랜딩의 각 섹션이 다음 행동 하나를 명확히 안내한다.
