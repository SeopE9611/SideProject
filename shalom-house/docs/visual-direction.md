# 샬롬의 집 시각 디자인 방향

## 1. 디자인 명제

샬롬의 집 홈페이지는 **공공기관의 명확한 정보 구조**와 **생활 기록이 주는 따뜻함**을 결합한다.

- 신뢰감은 큰 로고나 권위적인 문구가 아니라 정확한 정보, 예측 가능한 탐색, 충분한 대비에서 만든다.
- 따뜻함은 밝은 파스텔 장식이 아니라 쉬운 문장, 생활의 구체적인 장면, 승인된 실제 사진에서 만든다.
- 장애와 어려움을 감정적 후원 유도 수단으로 사용하지 않는다.

## 2. 핵심 인상

1. 차분하고 믿을 수 있는 기관
2. 사람이 실제로 생활하는 집
3. 필요한 정보를 쉽게 찾을 수 있는 홈페이지
4. 과장 없이 참여 방법을 설명하는 시설

## 3. 시각 언어

### 색상

- 웜 아이보리를 기본 배경으로 사용한다.
- 깊은 포레스트 그린은 주요 제목, 내비게이션, 핵심 행동에 사용한다.
- 테라코타는 섹션 레이블과 보조 강조에만 제한한다.
- 파스텔 색면을 여러 개 나란히 배치하지 않는다.
- 순수 검정과 순수 흰색의 강한 대비를 페이지 전체에 반복하지 않는다.

### 타이포그래피

- 제목은 굵고 명확하게, 본문은 17px 이상과 넉넉한 행간으로 제공한다.
- 한 페이지에서 가장 큰 제목은 `h1` 한 개로 제한한다.
- `word-break: keep-all`과 `overflow-wrap: break-word`를 함께 사용한다.
- 감성 문구를 여러 섹션 제목에 반복하지 않는다.

### 표면과 경계

- 카드보다 제목, 여백, 구분선으로 정보 계층을 만든다.
- 모서리는 기능적 컨트롤과 제한된 핵심 패널에만 사용한다.
- 그림자는 떠 있는 내비게이션과 독립 표면에만 약하게 사용한다.
- 숫자, 색면, 선 아이콘을 빈 사진 영역의 대체물로 사용하지 않는다.

## 4. 사진 원칙

- 공개 동의와 개인정보 검토를 마친 실제 시설·공간·활동 사진을 최우선으로 사용한다.
- 스톡 사진이나 AI 생성 인물을 실제 거주인 또는 시설 모습처럼 사용하지 않는다.
- 승인 사진이 없으면 사진 영역을 생략하고 문서형 레이아웃을 사용한다.
- 사진은 불쌍함이나 고립이 아니라 생활, 관계, 공간, 활동의 맥락을 보여 준다.
- 정보 전달 목적의 사진은 의미 있는 대체 텍스트를 제공한다.

## 5. 정보 구조

### 헤더

- 데스크톱은 시설 유형·찾아오시는 길·대표 전화를 제공하는 얇은 정보 바와 주 내비게이션으로 구성한다.
- 주 메뉴는 버튼 묶음이 아닌 텍스트 기반 탐색으로 표시한다.
- 현재 위치는 굵기와 하단 경계로 구분한다.
- 실제 하위 페이지가 있는 메뉴에만 드롭다운을 제공한다.

### 공개 페이지 상단

- 페이지 목적, 설명, 첫 행동을 왼쪽에 배치한다.
- 오른쪽 요약 영역은 해당 페이지에서 확인할 정보를 설명 목록으로 정리한다.
- 보조 영역을 여러 색상의 타일로 분리하지 않는다.

### 본문

- 설명형 콘텐츠는 편집형 목록과 구분선을 사용한다.
- 이동 목적이 분명한 항목에만 전체 영역 링크를 사용한다.
- 빈 상태를 오류나 홍보 카드처럼 과장하지 않는다.
- 관련 링크는 현재 맥락에서 필요한 경로만 제공한다.

### 푸터

- 시설 설명, 이용 안내, 연락처의 세 영역으로 구성한다.
- 주소와 대표 전화는 푸터에서 쉽게 찾을 수 있어야 한다.
- 공개 승인된 정보만 안내한다는 운영 원칙을 명시한다.

## 6. 페이지별 역할

| 경로 | 핵심 역할 | 중심 콘텐츠 |
| --- | --- | --- |
| `/` | 사이트 입구 | 시설 정체성, 주요 경로, 일상, 최근 소식, 함께하기 |
| `/about` | 공식 시설 소개 | 시설 유형, 생활 기준, 생활 모습, 방문 경로 |
| `/life` | 생활과 활동 소개 | 일상 장면, 활동 사례, 기록 원칙 |
| `/news` | 소식 탐색 | 제목, 분류, 게시일, 요약 |
| `/support` | 참여 안내 | 후원·자원봉사 준비, 문의 절차, 대표 전화 |
| `/transparency` | 공개 자료 탐색 | 자료 분류, 기준 기간, 게시일, 파일 형식 |

## 7. 모션과 상호작용

- 첫 화면은 짧은 페이드·상승 전환만 사용한다.
- hover는 클릭 가능한 요소에만 적용한다.
- 자동 재생 캐러셀, 배경 영상, 패럴랙스를 사용하지 않는다.
- `prefers-reduced-motion: reduce`에서는 애니메이션과 전환 시간을 최소화한다.
- 키보드 포커스는 색상과 외곽선으로 명확하게 표시한다.

## 8. 금지 패턴

- 여러 파스텔 타일을 조합한 대시보드형 히어로
- 내용을 채우기 위한 거대한 숫자와 단어
- 사진을 가장한 추상 그래픽과 선 아이콘
- 모든 섹션의 둥근 카드화
- 확인되지 않은 통계, 후원 계좌, 모집 일정, 운영 정보
- 장애인의 삶을 불쌍함이나 감동의 소재로 표현하는 문구
- 접근성 검증 전 WA 인증 또는 적합 완료 표현

## 9. 사진 도입 시 교체 순서

1. 메인 히어로의 보조 영역
2. 생활이야기의 대표 활동 장면
3. 시설소개 생활 공간
4. 최근 소식의 게시물별 대표 이미지

사진을 추가해도 현재의 제목 구조, 설명 목록, 키보드 탐색과 정보 순서는 유지한다.
