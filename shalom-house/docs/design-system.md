# 샬롬의 집 디자인 시스템

## 1. 목적

이 문서는 샬롬의 집 공개 화면의 색상, 타이포그래피, 간격, 공통 컴포넌트와 접근성 기준을 정의한다. 공식 CI가 확정되면 의미 토큰 이름은 유지하고 값만 교체한다.

## 2. 원칙

- 정보 구조 우선
- 따뜻하지만 절제된 색상
- 쉬운 문장과 충분한 글자 크기
- 카드보다 구분선과 여백
- Server Component 중심 구현
- WCAG 2.2 AA 설계 목표

## 3. 색상 토큰

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `background` | `#F7F4ED` | 전체 배경 |
| `surface` | `#FFFFFF` | 독립 콘텐츠 표면 |
| `surface-subtle` | `#EEF2EE` | 보조 정보 영역 |
| `foreground` | `#202F35` | 기본 텍스트 |
| `muted-foreground` | `#58655F` | 보조 텍스트 |
| `border` | `#D7DDD7` | 장식 경계 |
| `border-strong` | `#6F7D76` | 기능·구조 경계 |
| `primary` | `#245246` | 주요 행동과 현재 위치 |
| `primary-hover` | `#193F36` | 주요 행동 hover |
| `primary-soft` | `#E6EFEA` | 약한 주요색 배경 |
| `accent` | `#A95336` | 제한적 따뜻한 강조 |
| `accent-soft` | `#F4E9E3` | 참여 안내 hover |
| `home-ink` | `#183B3B` | 핵심 어두운 패널 |
| `home-cream` | `#F1ECE2` | 편집형 섹션 배경 |
| `focus-ring` | `#A95336` | 키보드 포커스 |

`home-sun`, `home-coral`, `home-sky`, `home-lilac`는 기존 화면 호환을 위해 유지하지만 새 공개 컴포넌트에서 반복 사용하지 않는다.

## 4. 타이포그래피

외부 웹폰트 없이 시스템 sans-serif 스택을 사용한다.

| 유틸리티 | 크기 | 용도 |
| --- | ---: | --- |
| `text-display-lg` | `3.5rem` | 데스크톱 페이지·섹션 제목 |
| `text-display` | `2.5rem` | 모바일 페이지·섹션 제목 |
| `text-title` | `2rem` | 주요 콘텐츠 제목 |
| `text-heading` | `1.5rem` | 목록·카드 제목 |
| `text-body` | `1.0625rem` | 본문 |
| `text-small` | `0.9375rem` | 보조 정보 |

- 큰 제목의 자간은 `-0.03em`에서 `-0.055em` 범위로 제한한다.
- 본문 행간은 `1.75`를 기본으로 한다.
- 핵심 정보는 `text-small`보다 작게 표시하지 않는다.

## 5. 컨테이너와 간격

- `max-w-site`: `80rem`
- `max-w-content`: `46rem`
- `px-page`: `1.25rem`
- `px-page-wide`: `3rem`
- 기본 섹션 간격: 모바일 `5rem`, 데스크톱 `6~7rem`
- 본문 단락 최대 폭: `46rem`

## 6. 모서리와 그림자

- `rounded-control`: `0.5rem`
- `rounded-card`: `0.875rem`
- `rounded-panel`: `1.25rem`
- `shadow-card`: 낮은 독립 표면에만 사용
- `shadow-nav`: sticky 헤더에 사용
- `shadow-elevated`: 드롭다운처럼 실제로 떠 있는 표면에만 사용

## 7. 공통 컴포넌트

### `SiteHeader`

- 데스크톱 정보 바와 주 내비게이션을 제공한다.
- 모바일에서 정보 바를 숨기고 메뉴 버튼을 제공한다.
- 사이트명은 장식 로고보다 텍스트 식별을 우선한다.

### `SiteNavigation`

- 현재 경로는 `aria-current="page"`, 굵은 글자, 하단 경계로 구분한다.
- `/support`는 테라코타 filled CTA로 제한적으로 강조한다.
- 드롭다운은 Escape, 외부 클릭, 포커스 이탈로 닫힌다.
- 모바일 메뉴는 문서 흐름을 유지하는 disclosure 구조다.

### `PageHero`

- 공개 하위 페이지의 목적, 설명, 핵심 행동과 요약 정보를 제공한다.
- 왼쪽은 큰 제목과 설명, 오른쪽은 `dl` 기반 설명 목록이다.
- 장식용 통계, 파스텔 타일, 추상 이미지를 포함하지 않는다.

### `HomeHero`

- 정적 히어로로 제공한다.
- 시설 정체성, 소개·생활 경로, 생활·활동·공개 기준을 한 화면에 배치한다.
- 실제 운영 콘텐츠가 없는 상태에서 캐러셀을 사용하지 않는다.

### 정보 목록

- 동일 위계의 항목은 `border-top`, `border-bottom`과 일정한 간격으로 구분한다.
- 번호는 순서가 의미 있을 때만 사용한다.
- 일반 설명을 카드로 감싸지 않는다.

### 빈 상태

- 오류 상태처럼 보이는 경고 아이콘을 사용하지 않는다.
- 현재 상태, 다음 변화, 대체 경로를 짧게 안내한다.
- 가짜 문서, 가짜 사진, 장식 통계를 생성하지 않는다.

## 8. 버튼과 링크

- 주요 행동은 `primary` 배경의 직사각형 버튼을 사용한다.
- 보조 행동은 밑줄이 있는 텍스트 링크를 사용한다.
- 클릭 영역의 최소 높이는 `44px` 이상이다.
- 링크 목적은 주변 문맥 없이도 이해할 수 있게 작성한다.
- 새 창 링크는 문구 또는 화살표 기호로 구분하고 `target="_blank"`와 `rel="noreferrer"`를 함께 사용한다.

## 9. 접근성

- 일반 텍스트 대비는 최소 `4.5:1`을 목표로 한다.
- 큰 텍스트와 기능 경계는 최소 `3:1`을 목표로 한다.
- 포커스는 `outline`과 `outline-offset`을 사용한다.
- 색상만으로 현재 위치, 상태, 분류를 전달하지 않는다.
- 페이지마다 `h1`은 한 개만 사용하고 제목 단계를 건너뛰지 않는다.
- `SkipLink`와 `main#main-content`를 유지한다.
- `prefers-reduced-motion` 환경에서는 애니메이션을 최소화한다.

## 10. 콘텐츠와 사진

- 확인된 `siteConfig`, 승인된 게시물, 공개 승인 자료만 사용한다.
- 사진은 공개 동의와 개인정보 검토를 통과한 실제 자료만 사용한다.
- 승인 사진이 없으면 이미지 컨테이너 자체를 만들지 않는다.
- 스톡 사진과 AI 생성 인물을 실제 시설 생활처럼 표현하지 않는다.

## 11. 검증

변경 후 다음 순서로 확인한다.

1. `pnpm typecheck`
2. `git diff --check`
3. 데스크톱·모바일 제목 줄바꿈과 가로 스크롤
4. 키보드로 헤더, 드롭다운, 모바일 메뉴, 링크 탐색
5. 200% 확대와 텍스트 간격 변경
6. 실제 승인 사진 연결 후 대체 텍스트와 개인정보 재검수
