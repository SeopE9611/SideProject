# 디자인 시스템

## 브랜드 방향

- 공공기관의 명확성과 복지기관의 존중·따뜻함을 함께 전달한다.
- 장식보다 실제 정보를 우선하고 감정적인 후원 유도를 하지 않는다.
- 일반 감성 문구 대신 실제 생활과 관계를 구체적으로 설명한다.

## 레이아웃

- 기본 최대 폭은 `1200~1280px` 범위, 기본 그리드는 12열로 한다.
- 하위 페이지는 콘텐츠 목적에 따라 본문 폭과 열 구성을 달리한다.
- 첫 화면에서 다음 핵심 정보 일부가 보이도록 과도한 히어로 높이를 피한다.
- 정보가 적다는 이유로 글자와 여백을 과도하게 키우지 않는다.

## 타이포그래피

- 홈 대표 제목은 최대 `64px`, 일반 하위 페이지 제목은 최대 `48px`, 목록·검색 페이지 제목은 최대 `40px`다.
- 본문은 `16~18px`, 보조 정보는 `14~16px`를 기준으로 한다.
- 모든 페이지 제목을 디스플레이 타이포그래피로 처리하지 않는다.
- 한국어에는 `word-break: keep-all`과 `overflow-wrap: break-word`를 함께 적용한다.

## 표면 유형

### 기본 콘텐츠 영역

흰색 또는 중립 배경에 그림자 없이 제목, 여백과 구분선으로 계층을 만든다.

### 기능 카드

이동, 프로그램, 자료, 연락처처럼 독립된 기능에만 명확한 테두리, 작은 모서리와 일관된 내부 간격을 사용한다.

### 강조 패널

핵심 공지, 참여 CTA, 중요 안내에 페이지당 최대 1개를 기본으로 사용하며 장식용으로 반복하지 않는다.

## 색상

- 기본 배경은 흰색과 중립 회색이며 전체 페이지를 웜 아이보리로 채우지 않는다.
- 포레스트 그린은 브랜드와 주요 행동, 테라코타는 제한적인 강조와 상태에 사용한다.
- 크림색은 생활 이야기나 참여 영역 일부에만 사용한다.
- 짙은 녹색 대형 패널을 모든 페이지에 반복하지 않는다.
- 기존 코드의 의미 토큰을 사용할 수 있지만 토큰 존재가 현재 배치의 보존 근거는 아니다.

## 사진

- 공개 승인된 실제 사진을 최종 우선으로 한다.
- 개발 단계에는 비인물 시설 외관, 공간, 식탁, 정원, 활동 도구 중심 placeholder를 사용할 수 있다.
- placeholder를 실제 시설 사진처럼 설명하지 않는다.
- 대표 이미지는 문맥에 맞춰 `3:2` 또는 `4:3`, 목록 썸네일은 한 목록 안에서 같은 비율을 기본으로 하고 초점 대상을 잘라내지 않도록 크롭 위치를 검토한다.
- 정보 이미지에는 목적과 맥락을 설명하는 대체 텍스트를 제공한다.
- 텍스트 위에 과도한 어두운 오버레이를 쓰거나 사진 부재를 감성 인용문 패널로 반복해 대체하지 않는다.

## 시각적 밀도

지나치게 큰 제목과 빈 공간, 동일한 세로 리듬, 모든 항목의 카드화 또는 선 목록화, 페이지 전체가 텍스트만 있는 상태, 데이터가 적은데 화면만 길어지는 상태를 피한다.

## 공통 컴포넌트 역할

- 기관 헤더와 유틸리티 내비게이션
- 브레드크럼과 소형 페이지 헤더
- 홈 전용 인트로
- 공지 목록과 활동 카드
- 프로그램 또는 지원 영역 카드
- 문서 목록과 절차 단계
- 연락 및 방문 패널과 푸터

기존 `PageHero`를 모든 페이지의 필수 패턴으로 정의하지 않는다. 컴포넌트는 외형 반복이 아니라 위 역할과 페이지 과업을 기준으로 공유한다.

기관 헤더는 필요하면 시설 유형·찾아오시는 길·승인된 대표 연락처를 제공하는 유틸리티 영역과 텍스트 기반 주 내비게이션으로 구성한다. 현재 위치는 색상 외 굵기·경계로도 구분하며 실제 하위 페이지가 있는 메뉴에만 하위 탐색을 제공한다. 푸터에서는 시설 설명, 이용 안내와 승인된 연락 정보를 찾기 쉽게 구분한다.

hover는 상호작용 요소에만 사용한다. 자동 재생 캐러셀, 배경 영상과 패럴랙스를 사용하지 않으며 모션을 제거해도 정보와 기능이 유지되어야 한다.
