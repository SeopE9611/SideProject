# 웹 접근성 기준

## 문서 목적과 적용 기준

이 문서는 장애인과 고령자를 포함한 모든 사용자가 공개 정보와 기능을 이용하기 위한 장기 기준이다. WCAG 2.2 AA를 우선 설계 목표로 하고 국내 웹 콘텐츠 접근성 지침 2.2를 함께 검토한다. 법률 자문이나 품질인증을 대신하지 않으며 자동·정적 검사만으로 적합을 선언하지 않는다.

과거 검사 결과는 `audits/`의 날짜별 기록으로 분리한다. 실제 브라우저, 보조기술 또는 사용자 검사를 실행하지 않은 항목은 통과로 표현하지 않는다.

## 구조와 탐색

- 문서 언어를 `ko`로 지정하고 `header`, `nav`, 단일 `main`, `footer`를 의미에 맞게 사용한다.
- 본문 바로가기, 논리적인 제목 단계와 현재 위치를 제공한다.
- 이동은 링크, 동작은 버튼을 사용하며 이름만으로 목적을 이해할 수 있게 한다.
- 기본 HTML을 우선하고 ARIA는 필요한 역할·상태·이름을 보완할 때만 사용한다.

## 키보드, 포커스와 대상 크기

- 모든 기능을 키보드로 조작하고 논리적인 포커스 순서와 가려지지 않는 `:focus-visible` 표시를 제공한다.
- 메뉴와 오버레이의 열기·닫기, `Escape`, 포커스 복귀와 키보드 함정을 실제 브라우저에서 확인한다.
- 주요 대상은 가능한 한 `44 × 44 CSS px` 수준을 목표로 하며 인접 대상 사이에 충분한 간격을 둔다.

## 색상, 확대와 움직임

- 일반 텍스트, 큰 텍스트, UI 경계와 상태별 대비를 실제 조합에서 검사한다.
- 상태, 오류, 선택과 중요도를 색상만으로 전달하지 않는다.
- 320 CSS px 폭 reflow와 브라우저 200% 및 400% 확대에서 정보·기능 손실, 겹침과 불필요한 가로 스크롤이 없어야 한다.
- `prefers-reduced-motion`을 존중하고 자동 재생, 깜빡임, 과도한 패럴랙스를 사용하지 않는다.

## 이미지와 미디어

- 정보 이미지에는 목적과 맥락에 맞는 대체 텍스트를 제공한다.
- fixture와 placeholder 이미지도 placeholder라는 이유로 빈 `alt`를 사용하지 않는다.
- 시각적 의미가 전혀 없는 장식 이미지만 빈 `alt`를 사용한다.
- 대체 텍스트에서 외모나 장애를 불필요하게 묘사하지 않는다.
- 영상에는 자막, 대본과 필요한 화면해설을 검토하고 음성만으로 필수 정보를 전달하지 않는다.

## 패턴별 기준

### 카드

- 제목과 설명의 읽기 순서를 유지하고 카드 전체 링크 안에 별도 상호작용 요소를 중첩하지 않는다.
- 카드 모양이나 색상만으로 클릭 가능 여부와 상태를 나타내지 않는다.

### 목록

- 실제 목록은 `ul`·`ol`을 사용하고 제목, 분류, 날짜와 상태의 관계를 읽기 순서로 이해할 수 있게 한다.
- 같은 `더 보기` 문구를 반복하지 않고 링크 목적을 구체적으로 제공한다.

### 검색과 필터

- 입력과 선택 항목에 영구적인 레이블을 제공한다.
- 적용된 조건, 결과 수, 결과 없음과 초기화 방법을 텍스트로 알리고 결과 갱신과 포커스를 검증한다.

### 문서 다운로드

- 문서명, 기준 기간, 게시일, 파일 형식과 크기를 링크 전에 제공한다.
- 새 창이나 다운로드 동작을 사전에 알리고 PDF 자체의 제목, 태그, 읽기 순서, 표와 대체 텍스트를 별도로 검사한다.

## 폼과 콘텐츠

- 입력에 연결된 레이블을 제공하고 필수 여부를 색상이나 별표에만 의존하지 않는다.
- 오류의 위치, 원인과 해결 방법을 안내하고 반복 입력을 최소화한다.
- 쉬운 한국어와 예측 가능한 메뉴·기능 이름을 사용한다.
- 텍스트 간격 변경에도 콘텐츠가 잘리거나 겹치지 않아야 한다.

## 검증 기록 원칙

- 자동 검사, 코드 정적 확인, 실제 브라우저, 키보드, 스크린리더와 사용자 검사를 구분한다.
- 320px reflow, 200%·400% 확대, 전체 키보드 탐색, 대상 크기, 색상 외 상태 표현, forced-colors와 `prefers-reduced-motion`을 해당 환경에서 확인한다.
- 실행 환경, 브라우저·운영체제·보조기술 버전, 경로, 재현 절차와 실제 결과를 기록한다.
- 실행하지 않은 환경과 항목은 `미실행` 또는 `확인 필요`로 남긴다.
