# 뱃지 시스템 V2

## 계열별 역할

- **Badge**: 모든 뱃지가 공유하는 색상, 크기, 모양의 저수준 기반이다. 기존 variant와 기본 pill 모양은 호환성을 위해 유지한다.
- **SemanticBadge**: 의미 색상(tone)과 강조 방식(emphasis)을 조합하는 일반 상태 뱃지다. 기본 모양은 `rounded`다.
- **CommerceBadge**: 상품과 라켓의 `NEW`, 추천, 할인, 인기, 정품, 품절을 표현하는 마케팅 뱃지다. 기본 모양은 `pill`이다.
- **RacketBadge**: 중고 라켓의 상태 등급, 구매 가능·구매와 대여 가능 여부, 검수 완료를 표현한다. `inline`과 `image` surface를 구분한다.
- **IdentityBadge**: 카카오·네이버 계정과 관리자 역할처럼 사용자 정체성을 표현한다. 업무 상태 뱃지로 대체하지 않는다.
- **카운트 뱃지**: 장바구니 수량, 읽지 않은 알림 수, 관리자 사이드바 건수를 짧게 표시하며 상태 의미를 갖지 않는다.

## 의미 색상과 강조 방식

- `neutral`: 기본 정보, 미확정, 이용 불가 또는 완료되어 더 이상 행동할 수 없는 상태
- `info`: 새로운 정보, 안내, 정상적인 진행 정보
- `success`: 성공, 이용 가능, 좋은 상태
- `warning`: 주의, 재고 부족, 대기 또는 확인 필요에만 사용
- `danger`: 오류, 위험, 할인처럼 즉각적인 주목이 필요한 정보
- `brand`: 브랜드가 주도하는 일반 강조와 인기 상품
- `signal`: 추천처럼 브랜드 안에서 가장 명확한 발견 신호

`soft`는 일반적인 인라인 정보에, `solid`는 이미지 위나 품절·판매 완료 같은 강한 상태에 사용한다. `outline`은 정품·검수 완료처럼 보조적인 확인 정보와 비활성 상태에 사용하며, outline에서도 tone의 의미 색상을 유지한다. 색상만으로 의미를 전달하지 않고 항상 이해 가능한 텍스트 라벨을 함께 노출한다.

상품의 인기는 warning이 아닌 brand를 사용한다. 정품은 surface와 관계없이 info outline을 유지하여 이미지 위의 NEW(info solid)와 구분한다. 할인율은 반올림한 1~100 범위의 정수로 정규화하며 유효하지 않은 값은 `SALE`로 표시한다.

라켓은 `구매 가능`과 `구매·대여 가능`을 구분하고, 재고가 모두 대여된 경우 `전량 대여 중`으로 표시한다. RacketBadge의 이미지 surface에서는 등급, 검수 완료, 이용 가능 상태를 solid로 표시하되 inline과 같은 tone과 라벨을 유지한다.

## 크기

- `xs`: 관리자 카운트와 매우 좁은 메타 정보 전용이다.
- `sm`: 기존 Badge와 같은 기본 크기이며 기존 화면 호환에 사용한다.
- `md`: 고객이 보는 상품, 라켓, 상세 상태에 사용한다.

고객 화면에서 `text-ui-micro`를 무분별하게 사용하지 않는다. 새로운 고객용 뱃지는 우선 `md`를 검토한다.

## 일관성 규칙

- 이미지 위 마케팅 뱃지는 우선순위 순으로 최대 2개만 노출한다.
- 같은 의미는 상품 목록·상세·라켓 등 모든 페이지에서 같은 문구와 tone을 사용한다.
- 상태 표현을 위해 raw `<span>`과 임의의 Tailwind 색상 클래스를 새로 만들지 않는다.
- 기존 디자인 토큰만 사용하며 raw 색상값을 추가하지 않는다.
- 정체성 및 카운트 뱃지를 마케팅·업무 상태 뱃지와 섞지 않는다.
- 각 컴포넌트는 계산된 spec의 shape를 그대로 재사용하고 같은 결정을 하드코딩하지 않는다.
- 저수준 `Badge`는 인라인 문맥과 버튼 내부에서 유효한 HTML을 만들도록 `span`을 렌더링한다.
- 라켓 케어의 교체 상태와 D-day는 `SemanticBadge`로 렌더링한다.

## 스트링 상품 품절 정책

| 입력 | 품절 판정 |
| --- | --- |
| `inventory.status === "outofstock"` | 품절 |
| 옵션 없음, 재고 관리 안 함 | 구매 가능 |
| 옵션 없음, 일반 재고 0, `allowBackorder === true` | 구매 가능 |
| variant/gauge/color 중 구매 가능한 조합 있음 | 구매 가능 |
| 옵션 조합이 모두 `isSoldOut`이거나 재고 0 | 품절 |
| 옵션 재고 0, 상품의 `allowBackorder === true` | 품절(옵션별 백오더 미지원) |

옵션별 백오더는 상세 옵션 선택과 장바구니가 지원하지 않으므로 상품 수준의
`allowBackorder`만으로 옵션을 활성화하지 않는다. 이 규칙은 메인·목록·상세가 함께 쓰는
`isStringProductSoldOut`에 둔다.

## 라켓 availability 우선순위

`sold` → 판매 완료, `rented` → 전량 대여 중, `inactive`·`비노출`·`isVisible === false` →
현재 이용 불가를 먼저 적용한다. 그 뒤 실제 수량과 대여 수량을 판정하고, 판매 가능한 경우에만
`rental.enabled`에 따라 구매 가능 또는 구매·대여 가능을 표시한다.
