# 관리자 데스크톱 뷰포트 정책

- 관리자 콘솔은 데스크톱 전용이며 최소 캔버스 너비는 1280px이다. 권장 화면 너비는 1440px 이상이다.
- 실제 뷰포트가 1280px 미만이어도 데스크톱 레이아웃을 유지하고 페이지 가로 스크롤을 허용한다.
- 모바일 카드, 모바일 관리자 메뉴, 태블릿·휴대폰용 대체 UI를 새로 구현하지 않는다.
- 관리자 화면은 테이블과 다열 정보 구조를 우선하며, 새 페이지는 1280px 상태를 기본 Tailwind 클래스로 작성한다.
- 1400px 이상에서만 필요한 확장 레이아웃은 별도 breakpoint를 사용할 수 있다.
- Dialog와 Popover 등 오버레이는 실제 뷰포트 안에서 조작할 수 있도록 overflow 안전성을 계속 보장한다.
- 이 정책은 사용자 쇼핑몰의 반응형 정책과 별개이며 공개 페이지에는 적용하지 않는다.
